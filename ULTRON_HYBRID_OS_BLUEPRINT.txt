1. CORE PHILOSOPHY & SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
Ultron is not a linear script or simple automation macro; it is a decoupled,
multimodal Hybrid Operating System designed to interface natively with the Windows
subsystem. The architecture mirrors human biological conduits:

* No Micro-Engine Blocks Another: All inter-engine communication is event-driven
  via the central Synapse Bus (Nervous System).
* Zero Stack Trace Dumps: The Immune System (Watchdog Sentinel) catches runtime
  faults silently and displays a native GUI HUD Modal for self-healing.
* Mirror-Mode Dialect Adaptation: Dynamic cognitive detection switches feedback
  between natural English and colloquial Hinglish based on user input.

================================================================================
2. TOTAL SUBSYSTEM ENGINES & COMPONENT DIRECTORY
================================================================================

TOTAL CORE ENGINES: 7 DEDICATED DOMAINS (14 MICRO-SERVICES)

[01] NERVES (The Nervous System)
     Path: 02_Nerves/synapse_bus.py
     * Engine: SynapseBus Pub/Sub Event Conduit.
     * Function: Asynchronous message bus. Routes telemetry, directives, and
       vocal pulses across memory without circular module imports.

[02] BRAIN (The Cognitive Core)
     Path: 02_Brain/
     * Engine 1 (brain_engine.py): Intent classifier & LM Studio local inference.
     * Engine 2 (task_planner.py): Tactical multi-step action breakdown.
     * Engine 3 (working_memory.py): Session-bound context tracker (retains
       target application handles across continuous turns).
     * Engine 4 (language_mirror.py): Input parser that flags dialect (EN vs HI)
       and adapts spoken responses dynamically.

[03] SENSE & PERCEPTION (Sensory Organs - Eyes & Ears)
     Path: 01_Sense/ & 01_Voice/
     * Engine 1 (wake_detector.py): Continuous low-resource wake-word vigilance
       listening for "Ultron".
     * Engine 2 (surface_inspector.py): UI visual tree parser & window tracker.
     * Engine 3 (native_grounding.py): Win32/UIA boundary coordinate resolver
       (translates fuzzy target names like "Edit menu" to exact screen X/Y).

[04] VOCAL TRACT & LARYNX (Acoustic Feedback)
     Path: 06_Vocal/
     * Engine 1 (vocal_tract.py): Speech queue manager & dynamic synthesizer.
     * Engine 2 (audio_player.py): Non-blocking audio streamer with auto-cleanup.
     * Engine 3 (acoustic_damper.py): Feedback canceller. Mutes microphone
       admittance while Ultron is speaking to prevent acoustic loops.

[05] MUSCULOSKELETAL SYSTEM (Motor Execution & Hands)
     Path: 04_Spine/, 05_Motor/ & 03_Automation_Engines/
     * Engine 1 (reflex_planner.py): High-level physical action sequencer.
     * Engine 2 (motor_controller.py): Kinetic Bezier curve mouse trajectory
       interpolator (produces human-like movement instead of instant teleports).
     * Engine 3 (universal_operator.py): Direct Win32 input emulator for clicks,
       window switching, and keyboard strokes.
     * Engine 4 (closed_loop_verifier.py): UI post-action validation engine.
       Verifies if a clicked window opened or text was cleared before returning.

[06] IMMUNE SYSTEM & METRIC VITALITY
     Path: 01_Sense/ & 04_Display/
     * Engine 1 (system_watchdog.py): Background thread & heartbeat monitor.
       Tracks CPU/RAM spikes and catches deadlocks.
     * Engine 2 (watchdog_fixer.py): In-memory isolate restarter. Revives broken
       threads without restarting the entire workstation process.
     * Engine 3 (hud_crash_modal.py): Topmost native dark-themed card window
       displaying error summaries and a one-click "Fix & Revive" button.

[07] LIFE PULSE (The Biological Heartbeat)
     Path: life_pulse.py & main.py
     * Engine: Master lifecycle bootstrapper. Orchestrates the Wake -> Listen
       -> Decide -> Act -> Verify bounded loop.

* Hook unhandled exceptions to spawn `hud_crash_modal.py` directly on the display.
